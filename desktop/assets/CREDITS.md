# Platform logo sources

Game Boy/Famicom assets downloaded on 2026-09-14; NES on 2026-09-15. The SVGs are preserved byte-for-byte, including their
original colors and paths. The app scales them proportionally on a light backing
so the original dark lettering remains legible in both desktop themes.

All five source pages mark the files **PD-textlogo** (public domain simple text
logos) and identify trademark restrictions separately. Nintendo retains its
trademarks. These marks identify supported platforms; Cartridge Studio is
independent software and is not affiliated with or endorsed by Nintendo.

## Project website

The static website reuses the original Cartridge Studio icon and the five
platform logos above without changing their paths or colors. Its desktop
screenshot is rendered from Cartridge Studio 0.1.0-beta.1 with synthetic HOMEBREW
metadata, a deterministic test path and no commercial game artwork or ROM data.
